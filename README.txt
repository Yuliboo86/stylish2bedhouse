STYLISH 2 BED HOUSE — FREE STATIC WEBSITE

Files:
- index.html
- images/ (property photos extracted from the supplied brochure)

Before publishing:
1. Open index.html in a browser to preview.
2. Replace the two booking buttons with the exact Airbnb and Booking.com listing URLs.
3. If you use a different email address, replace hello@stylish2bedhouse.com.
4. Upload the whole folder to a free static host such as GitHub Pages or Netlify.
5. Point stylish2bedhouse.com (managed at Wix) to the host using the host's DNS instructions.

The site is responsive and works on phones, tablets and desktops.
